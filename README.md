# Personal Portfolio

A personal portfolio website built to showcase my skills, projects, and experience as a web developer.

Live Demo: https://nouheh-portfolio.netlify.app/

This project is built using HTML, CSS, and JavaScript (Vanilla) to keep it lightweight, fast, and easy to maintain while focusing on clean design and usability.
